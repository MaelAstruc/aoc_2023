In two dimensions at time t

X(t) = ax + bx * t
Y(t) = ay + by * t

Two stones 0 and 1 intersect collide at time t1:

X0(t1) = X1(t1)
ax0 + bx0 * t1 = ax1 + bx1 * t1
t1 = - (ax0 - ax1) / (bx0 - bx1)

Y0(t1) = Y1(t1)
ay0 + by0 * t1 = ay1 + by1 * t1
t1 = - (ay0 - ay1) / (by0 - by1)

We can deduce:

X0(t1) = X1(t1) & Y0(t1) = Y1(t1)
=> (ax0 - ax1) / (bx0 - bx1) = - (ay0 - ay1) / (by0 - by1)
ax0 = ax1 + (ay0 - ay1) * (bx0 - bx1) / (by0 - by1)

We define ratios
DxUV = (axU - axV) / (bxU - bxV)
DyUV = (ayU - ayV) / (byU - byV)

We know that
t = - DxUV = - DyUV

We define DUV as a replacement

With a third stone 2 colliding with stone 0 at time t2

X0(t2) = X2(t2)
t2 = - (ax0 - ax2) / (bx0 - bx2)

Y0(t2) = Y2(t2)
t2 = - (ay0 - ay2) / (by0 - by2)

As before
=> ax0 = ax2 + (bx0 - bx2) * D02
